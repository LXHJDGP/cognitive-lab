# 认知实验室

一个中文个人认知训练工作台。工作日提供轮换计划，可按近期同题型表现调整难度，也可手动选题。程序是单文件网页，可直接在 Windows 浏览器中离线运行。

## 在 Windows 上运行

1. 在仓库页面选择 **Code → Download ZIP**，下载并解压。
2. 把 `index.html` 存在固定文件夹，用 Edge、Chrome 或 Brave 的普通窗口打开。
3. 从「今日工作台」开始，或从「训练模块」选一项练习。练完后点击「保存记录」。

## 训练与复盘

- **工作记忆更新**提供字母 N-back 和滚动记忆。1-back 比较当前字母和上一个字母，2-back 比较两个位置之前的字母。
- **操作广度**交替进行等式判断和字母回忆，两项分别计分。
- **渐隐式数学推导**从完整例题过渡到补全步骤和独立解题。
- **连续推理链**逐步练习条件规则、集合包含和先后约束。
- **单任务注意练习**围绕自定目标计时，支持记录中断和恢复线索。

训练记录提供逐题解析。每周复盘可对照同题型、同难度的成绩与耗时并保存笔记。「科学依据」页说明实验任务改编、教学方法和注意策略各自的适用范围。分数用于对照个人在具体任务上的表现。

## 本地记录与备份

历史存在浏览器里。请固定使用同一浏览器和文件路径，定期从「设置与备份」下载 JSON。换设备、浏览器或网址后，可导入 JSON 恢复。CSV 适合在 Excel 查看逐场汇总。训练备份可能含有私人备注，请自行保管。
