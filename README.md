# 认知实验室

一个中文个人认知训练工作台，聚焦于**怎样把一件需要连续思考的任务做下去**。比如做方程时，每一步单看都懂，连起来却容易丢掉中间结果。读一段论证时，可能推到结尾才发现漏用了一个前提。它也适合练习被打断后如何回到原任务。

## 怎么练

工作日默认轮换两项练习，再做一段真实的单任务练习，例如解一道题或读完一小节。可按近期同题型表现调整难度，也可以手动选题。

| 模块 | 练法 | 可以观察什么 |
| --- | --- | --- |
| 工作记忆更新 | 做字母 N-back，或按顺序回忆数字串的最后几位 | 字母比较的正确率，以及数字回忆中哪些位置容易漏答 |
| 操作广度 | 交替判断等式和记字母，最后按顺序回忆 | 等式判断和字母回忆各自的正确率 |
| 渐隐式数学推导 | 先看完整例题，再补最后一步、最后两步，最后独立解一道同类题 | 撤去提示后，能否独立完成同类题 |
| 连续推理链 | 从题内前提出发，逐步推出中间结论和最终结论 | 哪一步漏了条件、用反了规则，或推出了前提无法支持的结论 |
| 单任务注意练习 | 设置一个具体目标，计时，记录中断和恢复时的第一步 | 目标完成了多少、在哪里被打断、怎样接回去 |

练完后可看逐题解析，记录用力程度和卡住的步骤。每周复盘时，把同题型、同难度下的正确率、耗时和漏答放在一起看。例如，同类方程的独立题做得更准，耗时也更短，就值得看看自己现在是怎样写中间步骤的。

## 研究支持到哪一步

- **实验范式改编。** N-back、滚动记忆和操作广度源于工作记忆研究。本项目采用简化流程和固定时限，分数用于个人练习对照。[Kirchner（1958）](https://pubmed.ncbi.nlm.nih.gov/13539317/) · [Pollack 等（1959）](https://pubmed.ncbi.nlm.nih.gov/13641585/) · [Unsworth 等（2005）](https://doi.org/10.3758/BF03192720)
- **数学教学方法。** 渐隐式例题研究发现，从最后一步开始逐步撤去提示，有助于学习者过渡到相似新题的独立求解。[Renkl 等（2002）](https://freidok.uni-freiburg.de/data/47068)
- **领域练习与实践策略。** 推理链练习题内的演绎规则。单任务模块借鉴了中断研究，在切换前记下返回时要做的第一步。研究发现，写下恢复计划可以减少切到新任务时对原任务的持续惦记。[Leroy 与 Glomb（2018）](https://pubsonline.informs.org/doi/10.1287/orsc.2017.1184)

工作记忆更新训练在未练过的记忆跨度任务上观察到小幅迁移。对智力、阅读理解或算术等远迁移结果，现有证据仍不足。这里的研究支持来自各模块借鉴的方法，本项目整套训练的效果尚未经过独立验证。[Fu 等（2026）](https://link.springer.com/article/10.3758/s13423-026-02994-5) · [Melby-Lervåg 等（2016）](https://pmc.ncbi.nlm.nih.gov/articles/PMC4968033/)

## 在 Windows 上运行

1. 在在线工作台右上角点击「下载离线版」，会下载 `认知实验室.html`。也可以从 [GitHub 下载项目 ZIP](https://github.com/LXHJDGP/cognitive-lab/archive/refs/heads/main.zip)，解压取得 `index.html`。
2. 把下载的 HTML 存在固定文件夹，用 Edge、Chrome 或 Brave 的普通窗口打开。
3. 从「今日工作台」开始，或从「训练模块」选一项练习。练完后点击「保存记录」。

## 本地记录与备份

历史存在浏览器里。请固定使用同一浏览器和文件路径，定期从「设置与备份」下载 JSON。若要把在线工作台的记录带到离线版，先在在线工作台导出 JSON，再用离线版导入。CSV 适合在 Excel 查看逐场汇总。训练备份可能含有私人备注，请自行保管。
